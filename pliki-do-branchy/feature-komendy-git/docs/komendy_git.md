## Komendy Git

| Komenda | Zastosowanie |
|----------|--------------|
| git init | tworzy lokalne repozytorium |
| git status | pokazuje stan repozytorium |
| git add . | dodaje zmiany do staging |
| git commit -m "opis" | zapisuje zmiany w historii |
| git switch -c nazwa | tworzy i przełącza branch |
| git merge nazwa | scala branche |
| git remote -v | pokazuje repozytoria zdalne |
| git push | wysyła zmiany na GitHub |
